# Graphwise Workflows Helm Chart

This Helm chart makes it easy to deploy Graphwise Workflows in your Kubernetes cluster.

The repository can be added with the following command:

```shell
helm repo add graphwise-workflows https://poolparty-semantic-suite.github.io/graphwise-workflows-chart
```
