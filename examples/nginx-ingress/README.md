# Nginx Ingress Examples

The following folder contains several examples of how to configure the Graphwise Workflows deployment with Nginx
Ingress.

## Examples

1. [context-path](context-path.yaml) - Example of how to deploy the Workflows behind a context path and the related
   Nginx Ingress configurations.
2. [ingress-webhook-internal.yaml](ingress-webhook-internal.yaml) - Example of how to hide a particular API route from
   public access.
